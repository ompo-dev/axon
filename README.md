# AXON

Projeto de pesquisa de inteligencia artificial adaptativa, portatil e eficiente.
O prototipo atual tem capacidades delimitadas; nao foi demonstrada AGI.

Toda a visao, arquitetura, historia, resultados, erros, operacao e proximos passos
estao no [Documento Mestre](docs/AXON.md). Essa e a unica documentacao canonica.

```powershell
cargo build --release --bins
pwsh -File scripts/start-observatory.ps1 -NoBuild
```

Os documentos substituidos foram preservados integralmente no anexo do documento
mestre e num arquivo ZIP verificavel. Memorias, seeds e resultados nao foram apagados.
